# Normativas de inspección obligatoria en comunidades de propietarios — España

Datos abiertos publicados por [FincasAlDía](https://fincasaldia.es).

## Qué contiene

Listado de las normativas estatales y autonómicas de inspección
obligatoria en edificios residenciales de España, incluyendo:
- Nombre de la inspección
- Tipo (ITE, OCA, Revisión, Mantenimiento)
- Ámbito (estatal o CCAA específicas)
- Periodicidad en meses
- Normativa de referencia y artículo
- URL de la fuente oficial
- Rango de sanciones en euros

## Archivos

- `normativas.csv` — datos en formato CSV (separador: coma)
- `normativas.json` — datos en formato JSON
